# Decision Log

跨需求、长期有效的决定记在这里。只记会影响后续实现或评审的判断，不记流水账。

## 如何更新

- 一个决定一条，日期 + 标题。
- 写清楚**背景**、**决定**、**代价 / 后续动作**。
- 需求局部决定留在该需求的 `README.md`；只有跨需求才进本文件。
- 改变了旧决定时，在新条目里链接旧条目，不删除旧记录。

## 记录模板

### YYYY-MM-DD · 决策标题

**背景**：为什么现在必须定。

**决定**：选了什么，不选什么。

**代价 / 后续**：会影响哪些页面、文档、适配器或流程。
