# 原型操作台主界面

> 状态：📝 草案
> 创建日期：2026-10-20
> Feature Key：10202155_COCKPIT

## 需求背景（1-3 句）

操作台把「原型、批注、状态」放在同一屏，但当前顶栏动作语义重叠、左栏全是行话、原型区在启动和失败时接近空白、右栏四块信息互相抢注意力。目标是把信息层级重排成「一屏三栏、每栏一个主任务」，让专业用户快，让新用户不需要读文档。

## 验收标准

### 功能验收（能用）

1. 顶栏四个动作互不重复，批注数量与右栏一致。
2. 原型启动/加载有骨架与阶段文案，超过阈值提示慢响应。
3. 失败态提供重试、安装依赖、切换工作区与可展开日志。
4. 左栏状态为「阶段 · 结果」，三种状态都有文案。

### 体验验收（好用）

1. 进入操作台 3 秒内能看出「现在该点哪里」。
2. 帮助面板可用键盘打开与关闭，焦点回到触发按钮。
3. ⌘/Ctrl + Enter 可启动或重启原型，且不会在输入框误触发。
