## 需求背景（1-3 句）

原型是 Bee Press 的核心载体，之前却和 DSH 侧栏、Bee Press 品牌顶栏、左栏、常驻右栏层层叠加，画布被挤成一条。目标是把界面收成「一条 46px 图标栏 + 一条画布工具条 + 按需滑出的面板」，让复杂能力默认隐藏、需要时一步打开。

## 验收标准

### 功能验收（能用）

1. 原型画布占满除图标栏以外的区域，无品牌顶栏与常驻右栏。
2. 画布工具条只出现一次，评论模式/抽屉/内容台/预览宽度/刷新/外链各一个。
3. 图标栏六个阶段可切换，完成态有绿点，底部批注角标与面板一致。
4. 面板默认关闭，点批注或「下一步」滑出，Esc 关闭。
5. 启动/加载有骨架，失败有日志、重试、安装与切换工作区。

### 体验验收（好用）

1. 进入操作台 3 秒内能看出原型是主体、当前在哪个阶段。
2. 1024px 宽度工具条不换行、不溢出。
3. ⌘/Ctrl + Enter 可启动或重启原型，输入框内不触发。
