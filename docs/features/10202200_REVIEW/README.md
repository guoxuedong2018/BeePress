## 需求背景（1-3 句）

评审的价值在于「指出问题的位置」而不是「再写一遍问题」。当前能力已经能把批注锚到源码坐标，但新用户不知道要先开启点选，抽屉里也看不出是谁、什么时候留下的，解决后无法撤销。目标是把这条链路的可发现性和可恢复性补齐。

## 验收标准

### 功能验收（能用）

1. 首次进入能看到点选提示，关闭后按工作区记住。
2. 评论模式有明确开/关状态与光标反馈。
3. 抽屉显示作者、时间、路由、FRS。
4. 解决后 5 秒内可撤销。

### 体验验收（好用）

1. 新用户不看文档就知道怎么留下第一条批注。
2. 内嵌模式只有一条评审条，不会出现双入口。
